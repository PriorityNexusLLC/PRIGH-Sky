Every figure comes from the FEC's bulk files. Each time a new copy is published it is set beside the copy before it, and what is new, what is gone and what changed is listed here. Committees and candidates are matched by FEC number, never by name. A change is a filed fact to look at, not a finding about anyone: reports are amended and corrected all the time. Each name opens that committee's or candidate's own page at the FEC.

The files are checked every day and the changes are kept. One report is made for each week, Monday to Sunday, from 1 daily comparison in this one. Every earlier report stays open at the links above and in the list at the foot of the page. See also SEC changes, the same weekly report for the SEC's file of every filer.
