The SEC publishes one file a day with every filer's record and the list of everything it has ever filed. Each new copy is set beside the copy before it, and what is gone and what changed is listed here. Filers are matched by SEC number, never by name. Anyone who files with the SEC is in its public record, companies and people alike, so every filer is named. A change is a filed fact to look at, not a finding about anyone: filings are also removed for ordinary reasons (filed under the wrong filer, a duplicate, a correction). Each name opens that filer's own page at the SEC.

The file is checked every day and the changes are kept. One report is made for each week, Monday to Sunday, from 1 daily comparison in this one. Every earlier report stays open at the links above and in the list at the foot of the page. See also PAC movement, the same weekly report for the FEC's files.

What is not here

  • Addresses and phone numbers in the SEC's file are never read or stored.
  • A changed tax ID is listed only as changed. The number is never stored.
  • The source: the SEC's own bulk file, submissions.zip. Anyone can download the same file and see the same records.
